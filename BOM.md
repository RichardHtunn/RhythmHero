# Bill of Materials (BOM)

This document outlines the core hardware components required to build and run the Rhythm Hero system.

| Component | Quantity | Purpose in System |
| :--- | :--- | :--- |
| **Digilent Basys3 (Artix-7 FPGA)** | 1 | Core game logic, VGA signal generation, collision detection, and switch debouncing. |
| **Raspberry Pi (Model 3/4)** | 1 | Audio management. Listens for 3.3V GPIO triggers and executes low-latency audio playback. |
| **Arcade Push Buttons** | 4 | Physical user input. Wired as normally-open (NO) momentary switches. |
| **VGA Monitor** | 1 | Visual output. Displays the 12-bit color game interface generated by the FPGA. |
| **Active Speaker** | 1 | Audio output. Connected via the Raspberry Pi 3.5mm audio jack. |
| **Female-to-Female Jumper Wires**| 5 | Bridges the Basys3 Pmod header to the Raspberry Pi GPIO pins (4 signal wires, 1 common ground). |
| **Wire & Crimp Terminals** | - | For securely routing the arcade buttons to the FPGA Pmod inputs. |
